# Microservicios en Python

Aprenderás a diseñar, implementar y operar microservicios con Python, Docker y Kubernetes, integrando seguridad, persistencia y monitorización para crear aplicaciones distribuidas escalables y mantenibles.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [análisis de un monolito y propuesta de servicios](Capitulo01/README.md#análisis-de-un-monolito-y-propuesta-de-servicios)
  - Descripción: Analizar un monolito y elaborar una propuesta de servicios aplicando los principios, patrones y límites de responsabilidad del capítulo.
  - Duración estimada: 39 min

### Capítulo 2

- [crear una API REST simple en FastAPI](Capitulo02/README.md#crear-una-api-rest-simple-en-fastapi)
  - Descripción: Crear una API REST simple en FastAPI aplicando criterios de descomposición, diseño de recursos y contratos, y herramientas Python para APIs.
  - Duración estimada: 56 min

### Capítulo 3

- [construir y publicar una imagen Docker](Capitulo03/README.md#construir-y-publicar-una-imagen-docker)
  - Descripción: Construir y publicar una imagen Docker para un servicio Python aplicando fundamentos de contenedores, buenas prácticas de Dockerfile, optimización y seguridad básica.
  - Duración estimada: 64 min

### Capítulo 4

- [desplegar servicio Python en un clúster local (minikube/kind)](Capitulo04/README.md#desplegar-servicio-python-en-un-clúster-local-minikubekind)
  - Descripción: Desplegar un servicio Python en un clúster local con minikube o kind utilizando Pods, Deployments, Services, configuración y secretos básicos.
  - Duración estimada: 64 min

### Capítulo 5

- [montar un volumen persistente para un servicio Python](Capitulo05/README.md#montar-un-volumen-persistente-para-un-servicio-python)
  - Descripción: Montar un volumen persistente para un servicio Python aplicando PersistentVolumes, PersistentVolumeClaims, StorageClasses y conceptos de persistencia.
  - Duración estimada: 64 min

### Capítulo 6

- [crear un chart de Helm y escalar un deployment](Capitulo06/README.md#crear-un-chart-de-helm-y-escalar-un-deployment)
  - Descripción: Crear un chart de Helm y escalar un deployment aplicando mecanismos de escalado, balanceo de carga y automatización de despliegues.
  - Duración estimada: 63 min

### Capítulo 7

- [implementar autenticación JWT y TLS entre servicios](Capitulo07/README.md#implementar-autenticación-jwt-y-tls-entre-servicios)
  - Descripción: Implementar autenticación JWT y TLS entre servicios aplicando control de acceso y prácticas de comunicación segura descritas en el capítulo.
  - Duración estimada: 63 min

### Capítulo 8

- [persistencia híbrida (Postgres + Mongo) para un servicio](Capitulo08/README.md#persistencia-híbrida-postgres-mongo-para-un-servicio)
  - Descripción: Implementar persistencia híbrida con Postgres y Mongo para un servicio, integrando desde Python opciones SQL y NoSQL y los conceptos de consistencia del capítulo.
  - Duración estimada: 63 min

### Capítulo 9

- [implementar caching con Redis en servicio Python](Capitulo09/README.md#implementar-caching-con-redis-en-servicio-python)
  - Descripción: Implementar caching con Redis en un servicio Python aplicando tipos de datos, casos de uso y estrategias de invalidez y sincronización.
  - Duración estimada: 63 min

### Capítulo 10

- [instrumentar servicio con Prometheus, Grafana y Jaeger](Capitulo10/README.md#instrumentar-servicio-con-prometheus-grafana-y-jaeger)
  - Descripción: Instrumentar un servicio con Prometheus, Grafana y Jaeger para aplicar métricas, monitoreo y tracing distribuido conforme al contenido del capítulo.
  - Duración estimada: 64 min
